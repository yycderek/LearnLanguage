# LearnLanguage

LearnLanguage 是一个可切换语种的通用语言学习工具。产品通过统一的学习引擎运行不同语言包，并允许用户导入语料、创建私人课程。

## 在线使用

打开 [LearnLanguage 学习空间](https://learnlanguage-studio.yycderek.chatgpt.site/learn) 即可使用。无需 ChatGPT 登录，也不要求注册 LearnLanguage 账户；内置课程、学习进度和草稿默认保存在当前浏览器。

## 五分钟快速开始

### 开始学习

1. 打开学习空间后，在课程库选择日语或粤语内置课程。
2. 点击“一键开始学习”；系统会自动安装课程并进入当前应学课节。
3. 每课按“理解—练习—运用”三个学习阶段呈现。底层仍会执行诊断、输入、输出、反馈和迁移等细分环节。
4. 完成课节后，下一课会自动解锁；系统会根据掌握证据生成复习任务。
5. 在学习首页查看课程进度、掌握度和复习队列。

基础检查只用于选择学习路径，不是 CEFR 或 JLPT 考试成绩。当前内置课程的主等级是 CEFR Can-do A1 核心；日语内容仅标记为 JLPT N5 相关，不代表完整 N5 备考。

### AI 是可选的

不配置 AI 也可以完成单选、多选、排序、短输入和本地规则练习。自由回答或角色任务需要额外反馈时，可以在 Studio 右上角打开“AI 设置”，选择自己的服务商、模型和接口并先测试连接。

- 服务商、模型和接口地址保存在当前设备。
- API 密钥只保留在当前标签页，关闭标签页后清除。
- 项目不会要求使用 ChatGPT 登录来访问网页。

### 创建自己的课程

1. 打开 [课程创作空间](https://learnlanguage-studio.yycderek.chatgpt.site/studio)。
2. 选择目标语言，或创建／导入一个 Language Pack。
3. 从课程模板开始，在可视化界面维护知识点、例句、练习和课节流程；普通作者不需要编辑 JSON。
4. 保存草稿并使用临时档案预览。Studio 预览不会写入正式学习进度。
5. 完成发布检查后发布课程，再点击“安装到学习空间”进行正式学习。

草稿可以继续修改；已发布版本不可覆盖修改，需要创建派生草稿。创建素材、发布课程和安装到学习空间是三个不同动作。

### 本地数据与备份

无账户模式使用浏览器本地数据库。清除站点数据、更换浏览器或使用另一台设备时，本地内容不会自动出现。请按需要分别备份：

- 在课程库导出和恢复学习档案；
- 在 Studio 的本地草稿中导出课程草稿；
- 导出已发布课程和自定义 Language Pack；
- AI 密钥不会进入任何备份文件。

课程导入、学习档案备份和可选设备同步收在课程库底部的“课程与数据管理”中，不影响首次开始学习。网页首次打开会显示四步使用引导；之后可以通过 Learn 或 Studio 顶部的“使用帮助”重新打开。

## 产品方向

- 通用学习引擎：诊断、预教、分级输入、渐进输出、反馈重说、复习和迁移测试
- 可插拔语言包：封装文字、语法、分词、书写方向和难度框架等语言差异
- 可扩展课程包：官方课程、社区课程和用户私人课程使用统一格式
- 独立学习档案：用户切换语言时保留各语种各自的学习进度

## 当前阶段

R1–R5 技术基线和 R6 首条垂直链路已经完成：项目具备无头 TypeScript 学习引擎、Learn/Studio Web 产品空间、不可变课程发布、实际可执行的语言适配器、中文/英文教学语言、掌握与复习投影，以及账户可选的公开同步协议和参考服务。

当前阶段暂不提供发音、录音、语音识别或语音评分练习，优先完善文本学习、AI 反馈和课程内容流程。

## 本地开发

```bash
pnpm install
pnpm check
pnpm --dir apps/web install
pnpm --dir apps/web test
```

当前代码包括（R1–R18 主要框架已完成）：

- 通用语言定义与运行时适配器
- 统一的中文/英文应用语言偏好，同时控制界面、课程讲解和 AI 反馈，并支持本地化内容回退
- 可序列化课程包和学习流程协议
- 跨 Web、移动端和桌面端复用的草稿、语言包与课程库 Application Service
- 跨引用与流程完整性校验
- 可重放的课程会话状态机和学习事件
- 内存与 SQLite 事件存储、会话恢复和并发控制
- 掌握度投影与最小复习调度
- CoursePack JSON Schema、安全导入与分阶段错误报告
- 私人课程草稿、所有权和版本控制
- 日语、粤语参考语言包
- 日语、粤语首个中英双语 A1 核心课程库：每个语种包含 4 个文字／标音基础课、5 个高频能力课和 3 个场景课，并提供短文阅读、信息提取、独立练习与读音信息
- 无需登录的 Web 课程工作台
- 可视化 Course Pack 编辑器与 JSON 高级编辑模式
- 无代码多课节编排，可新增、排序、删除课节并分别维护每课的线性学习步骤
- 自定义 Language Pack 快速创建、JSON 导入和设备本地保存
- Language Pack 独立管理、导入导出和跨课程引用删除保护
- 发布、预览、安装、更新和学习入口统一执行语言适配器及练习能力兼容性门禁
- Web 课程播放器、反馈重试和课程完成总结
- 可注册练习渲染层，以及跨客户端复用的单选、多选、排序、文本与开放任务响应模型
- 设备本地学习进度、掌握度投影与复习任务生成
- 学习首页、多课节解锁、课程总进度和可执行复习队列
- 设备本地课程库，区分内置与用户课程，支持完整性校验安装、兼容更新、卸载及进度保留
- 无代码课程文件导入与导出：本地 JSON 文件经过发布状态、格式、大小和内容哈希检查后安装或更新
- 无账户学习档案备份与恢复，只携带完成记录、掌握度和复习计划，并按更新时间安全合并
- 用户自选 AI 服务的连接测试，以及自由回答和角色任务的文本反馈
- 公开同步协议、能力发现、增量游标、幂等提交和冲突检测
- 无外部依赖、无需账户的内存参考同步服务

- 内存、IndexedDB 与 SQLite Repository，以及共享合约测试和非 Web Headless 客户端验证
