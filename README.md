# LearnLanguage

LearnLanguage 是一个可切换语种的通用语言学习工具。产品通过统一的学习引擎运行不同语言包，并允许用户导入语料、创建私人课程。

## 产品方向

- 通用学习引擎：诊断、预教、分级输入、渐进输出、反馈重说、复习和迁移测试
- 可插拔语言包：封装文字、语法、分词、书写方向和难度框架等语言差异
- 可扩展课程包：官方课程、社区课程和用户私人课程使用统一格式
- 独立学习档案：用户切换语言时保留各语种各自的学习进度

## 当前阶段

R1–R5 技术基线和 R6 首条垂直链路已经完成：项目具备无头 TypeScript 学习引擎、Learn/Studio Web 产品空间、不可变课程发布、实际可执行的语言适配器、中文/英文教学语言、掌握与复习投影，以及账户可选的公开同步协议和参考服务。

当前阶段暂不提供发音、录音、语音识别或语音评分练习，优先完善文本学习、AI 反馈和课程内容流程。

## 本地开发

```bash
pnpm install
pnpm check
pnpm --dir apps/web install
pnpm --dir apps/web test
```

当前代码包括：

- 通用语言定义与运行时适配器
- 统一的中文/英文应用语言偏好，同时控制界面、课程讲解和 AI 反馈，并支持本地化内容回退
- 可序列化课程包和学习流程协议
- 跨引用与流程完整性校验
- 可重放的课程会话状态机和学习事件
- 内存与 SQLite 事件存储、会话恢复和并发控制
- 掌握度投影与最小复习调度
- CoursePack JSON Schema、安全导入与分阶段错误报告
- 私人课程草稿、所有权和版本控制
- 日语、粤语参考语言包
- 日语、粤语首个完整中英双语入门课程库：每个语种包含 3 个递进课节、独立练习与读音信息
- 无需登录的 Web 课程工作台
- 可视化 Course Pack 编辑器与 JSON 高级编辑模式
- 无代码多课节编排，可新增、排序、删除课节并分别维护每课的线性学习步骤
- 自定义 Language Pack 快速创建、JSON 导入和设备本地保存
- Web 课程播放器、反馈重试和课程完成总结
- 可注册练习渲染层，以及跨客户端复用的单选、多选、排序、文本与开放任务响应模型
- 设备本地学习进度、掌握度投影与复习任务生成
- 学习首页、多课节解锁、课程总进度和可执行复习队列
- 设备本地课程库，区分内置与用户课程，支持完整性校验安装、兼容更新、卸载及进度保留
- 无代码课程文件导入与导出：本地 JSON 文件经过发布状态、格式、大小和内容哈希检查后安装或更新
- 用户自选 AI 服务的连接测试，以及自由回答和角色任务的文本反馈
- 公开同步协议、能力发现、增量游标、幂等提交和冲突检测
- 无外部依赖、无需账户的内存参考同步服务
- 固定迁移样例、双 Node 版本 CI 和候选版本发布通道
