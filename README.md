# LearnLanguage

LearnLanguage 是一个可切换语种的通用语言学习工具。产品通过统一的学习引擎运行不同语言包，并允许用户导入语料、创建私人课程。

## 产品方向

- 通用学习引擎：诊断、预教、分级输入、渐进输出、反馈重说、复习和迁移测试
- 可插拔语言包：封装文字、注音、发音、语法、分词及语音服务差异
- 可扩展课程包：官方课程、社区课程和用户私人课程使用统一格式
- 独立学习档案：用户切换语言时保留各语种各自的学习进度

## 当前阶段

项目正在构建与 UI、数据库无关的 TypeScript 领域层。首个里程碑是让同一套课程引擎加载两种差异明显的语言包，并运行用户创建的课程。

## 本地开发

```bash
pnpm install
pnpm check
```

当前代码包括：

- 通用语言定义与运行时适配器
- 可序列化课程包和学习流程协议
- 跨引用与流程完整性校验
- 可重放的课程会话状态机和学习事件
- 内存与 SQLite 事件存储、会话恢复和并发控制
- 掌握度投影与最小复习调度
- 日语、粤语参考语言包
- 两个使用同一流程的示例课程

详细设计见 [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md)。
