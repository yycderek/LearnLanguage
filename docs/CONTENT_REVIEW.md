# 内置课程内容审校记录

## 状态定义

内容质量使用三层状态，避免把自动检查或来源核对误写成母语者审校：

1. **自动校验通过**：结构、引用、双语字段、读音字段和学习路径通过测试。
2. **来源核对完成**：项目维护者已根据列出的公开资料核对课程范围、书写／标音系统和任务设计。
3. **母语者签署完成**：具名母语者逐条检查自然度、地区用法、语域和错漏，并记录姓名与日期。

只有三层全部完成，课程才能标记为“已完成母语者审校”。

## 母语者审校清单

- 逐条检查目标语言、标音、翻译和提示是否相互一致。
- 标记“语法正确但不自然”“地区差异”“语域不当”和“事实错误”，并给出替换文本。
- 实际完成课程中的 3 至 4 个综合任务，确认任务说明明确、A1 学习者可完成、完成标准可观察。
- 确认课程未暗示音频、发音评分、完整 JLPT N5 备考或其他尚未提供的能力。
- 在本文件中记录审校者、日期、覆盖版本／提交和最终结论。
