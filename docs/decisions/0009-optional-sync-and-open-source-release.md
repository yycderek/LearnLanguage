# ADR 0009：可选同步协议与开源发布门禁

## 状态

已接受。

## 决策

- 同步是 Application 外部的可选适配器。断网、未配置服务或没有账户时，本地课程、学习、掌握投影和复习仍完整可用。
- 服务通过公开 well-known 端点声明协议版本、认证模式、资源、冲突策略和批量限制。客户端不得根据服务品牌推测能力。
- 档案 ID 与账户解耦；协议同时允许 `none` 和 `bearer` 认证。参考服务使用匿名档案和内存存储，不作为生产托管服务。
- 提交使用 mutation ID 去重，使用 base version 检测陈旧写入；服务端返回当前记录，由客户端显式解决冲突。
- 仓库采用 Apache-2.0。协议、兼容性、许可证、治理、安全、自部署、固定迁移样例和候选版本 CI 都是公开仓库前的发布门禁。
- 改变 GitHub 仓库可见性属于独立、显式的维护者操作；完成技术准备不会自动把 private 仓库改为 public。

## 结果

Web、移动端和桌面端可以共享同步语义而不共享界面或存储实现。社区可以自托管兼容服务，同时核心产品不会被某个账户系统、云平台或服务商绑定。
