# ADR 0002：课程会话使用可重放事件流

## 状态

已接受。

## 背景

课程运行需要记录用户是否依赖支架、经过几次尝试、收到什么提示以及何时完成迁移测试。数据库、Web 客户端、语音评分和 AI 反馈还没有确定，核心流程不能依赖其中任何一种实现。

## 决策

- 课程会话通过纯函数状态机推进。
- 每次推进产生带连续序号的可序列化事件。
- 当前状态可以完全由事件流重放得到。
- 客户端提交预期步骤和事件序号，拒绝重复或过期请求。
- 评分服务只负责给出通过或重试决定及学习证据，状态机负责流程推进。
- 多分支步骤必须明确选择课程定义中允许的下一步。

## 结果

未来可以将事件写入关系数据库、事件仓库或本地离线存储，而不改变课程流程。学习分析和掌握度计算也可以从相同事件流派生。
