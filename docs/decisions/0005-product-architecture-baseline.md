# ADR 0005：跨平台、离线优先的产品架构基线

## 状态

已接受。当前项目尚未公开使用，因此实施采用断代重构，不承诺兼容现有浏览器本地数据。

## 核心边界

- 采用模块化 Monorepo：`protocol -> engine -> application -> apps`，平台能力通过 Ports/Adapters 接入。
- UI 只发送 Command 并渲染结果；引擎不依赖 React、Next.js、DOM、网络、数据库或具体 AI 服务。
- Learn 与 Studio 是两个独立产品空间；安装已发布课程与导入创作素材使用不同流程。
- 本地档案是基础，账户、同步和官方托管都是可选能力。
- Web 使用 IndexedDB；未来桌面端与移动端使用 SQLite，并通过相同 Repository 合约测试。

## 内容与语言

- 课程草稿可修改；发布版本由 `courseId + version + contentHash` 标识且不可修改。
- 知识点默认属于课程，也可选择关联全局 `conceptId`；绝不按文本自动合并。
- 用户课程包是声明式数据，不得包含可执行代码。
- 文本层采用通用 Unicode 核心、可组合语言能力、课程级安全规则和明确降级机制。
- 课程固定所需语言适配器版本；缺少能力时允许自评、参考答案或禁用依赖练习。
- 发音、录音、TTS、STT 与语音评分不在当前实现范围。

## 学习与可靠性

- 学习记录采用追加事件与版本化快照；事件、快照、引擎和课程均记录版本。
- 课程进度、知识掌握度和复习调度分层维护。
- 评分来源分为确定性、自评和 AI 辅助；AI 默认不能直接决定掌握度。
- 外部调用由持久化 Effect 队列执行，目标语义是至少一次执行加幂等去重。
- 离线操作先写本地；同步追加学习事件并对草稿使用 revision 冲突检测。

## AI、安全与隐私

- AI 是不可信、可替换的外部能力；没有 AI 时核心学习与创作仍可运行。
- AI 输出先通过结构和领域校验，生成课程只能进入草稿。
- API Key 不进入课程、事件、普通数据库或同步；Web 默认仅保存在会话中。
- 导入内容、附件、AI 输出和自定义网络地址默认不可信，并执行大小、类型、路径与网络边界检查。
- 默认最小遥测且允许关闭；自部署可以完全不配置遥测。

## 开源与兼容

- 代码计划使用 Apache-2.0；课程内容单独记录许可证，公开发布时由作者明确选择。
- 声明式扩展稳定开放；代码适配器通过审查随构建发布；实验接口不承诺稳定。
- 协议、Schema、迁移器、合约测试和历史固定样例随源码发布。
- 目标语言与应用语言分别建模；应用语言统一界面和讲解，并支持 RTL、IME、键盘操作和屏幕阅读器。

## 实施策略

由于仓库仍为 private 且没有真实用户，取消旧 LocalStorage 数据迁移和线上双轨兼容：

1. 保存当前 Git 历史作为恢复点。
2. 建立唯一协议包并删除重复模型。
3. 迁移无头引擎和 Application 层。
4. 直接启用新的 IndexedDB 数据库。
5. 拆分 Learn 与 Studio，再替换当前部署。
