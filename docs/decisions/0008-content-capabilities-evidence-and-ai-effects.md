# ADR 0008：内容身份、语言能力、掌握证据与 AI Effect

## 状态

已接受。

## 决策

- 课程草稿可持续编辑；发布会生成不可变 Course Pack 身份。发布清单必须固定来源、许可证、语言适配器版本和 SHA-256 内容哈希。
- 安装发布课程前重新计算规范化内容哈希。校验失败的包不能进入学习空间；创建派生版本必须先 fork 成新草稿。
- 语言包声明它能提供的原子能力，练习声明 `requiredCapabilities`。缺少能力时，课程作者必须选用 `self-assessment`、`reference-answer` 或 `disabled` 降级，不允许客户端静默猜测。
- 通用引擎负责从事件重建掌握证据并生成复习计划。客户端仅保存并显示投影；被标为 `evidenceEligible: false` 的降级尝试不会提升掌握度，也不会生成复习任务。
- AI 调用以 `ai-feedback.requested` Effect 进入持久化队列。适配器只在结构化输出通过校验后完成该 Effect；AI 输出是参考意见，不能直接提交通过或重试决定，学习者仍需明确确认。

## 结果

Web、移动端和桌面端可以共享同一课程身份、能力解析、掌握投影和 Effect 语义，同时各自替换存储、网络和界面适配器。没有 AI、没有账户或缺少专用语言适配器时，确定性学习流程仍可运行且不会制造虚假的掌握证据。
