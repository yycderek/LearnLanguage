# ADR 0004：用户课程先经过 Schema 导入，再进入私人版本化草稿

## 状态

已接受。

## 决策

- 使用 JSON Schema 2020-12 描述可导入的课程包结构。
- 使用 Ajv 对未知 JSON 做运行时结构校验。
- 结构校验后继续执行课程引用和流程领域校验。
- 导入错误区分 JSON、Schema 和领域三个阶段，并提供路径。
- 用户创建的课程必须以私人、草稿状态开始，作者必须与所有者一致。
- 每次修改生成不可变的新修订版，并使用预期修订号避免覆盖并发更新。
- 提供内存和 SQLite 两种草稿存储。

## 结果

用户提交的未知数据不会直接进入课程引擎。课程编辑器可以按字段展示错误，并能查看历史版本或恢复持久化草稿。
