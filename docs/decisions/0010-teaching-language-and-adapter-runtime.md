# ADR 0010：教学语言与可执行语言适配器

## 状态

已接受。

## 决策

- 目标语言、教学语言和界面语言是三个独立维度。课程决定目标语言，设备偏好决定教学语言，客户端自行决定界面语言。
- 第一批正式教学语言与界面语言均为中文（默认）和英文。两种偏好使用不同的 `preferences` 记录，无需账户，也不进入确定性学习引擎状态；升级时若尚无界面语言偏好，则用已有教学语言初始化一次，之后独立变化。
- Course Pack 继续使用 `LocalizedText`，按精确 locale、同语种变体、中文/英文、native、首个可用值的固定顺序回退。AI 请求显式携带教学语言，并要求同语种输出。
- Studio 的学习界面和课程内容编辑相互区分；作者切换教学语言时编辑对应的本地化字段，而不是覆盖另一语言内容。
- Language Pack 的 adapter 字段是兼容性要求，不是能力事实。客户端通过独立的 `@learn-language/language-runtime` 注册表解析适配器，只有找到并能执行的能力才对练习公开。
- 内置适配器不得依赖 React、DOM、IndexedDB 或特定客户端。未安装专用适配器时，明确使用通用运行时或按练习声明降级；不得加载任意第三方 JavaScript。

## 结果

中文用户保持原有默认体验，英文用户可完成同一条课程学习、创作、复习和 AI 反馈链路。用户也可以组合中文界面与英文教学内容，或英文界面与中文教学内容。课程作者可逐步补齐翻译，Web、未来 App 和桌面客户端则共享相同的内容回退和语言处理能力，不与任何界面耦合。
