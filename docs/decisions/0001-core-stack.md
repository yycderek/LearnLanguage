# ADR 0001：先构建 TypeScript 通用领域层

## 状态

已接受。

## 背景

LearnLanguage 需要让 Web 界面、后台服务、课程编辑器和内容校验共享同一套语言包与课程包协议。现阶段不应让核心模型依赖某个 UI 框架、数据库或 AI 服务。

## 决策

- 使用严格模式 TypeScript 定义领域协议。
- 课程包保持纯数据结构，确保可以序列化、导入、版本化和校验。
- 语言包由可序列化定义与运行时适配器组成，以容纳规范化、分段等语言差异。
- 首阶段核心层不引入运行时依赖。
- 使用日语和粤语两个参考语言包验证通用性。
- 使用自动化测试约束跨对象引用和流程完整性。

## 暂不决定

- Web 框架和组件库
- 数据库与身份系统
- TTS、STT 和大模型供应商
- 课程分享与审核基础设施

这些选择将在核心协议稳定后单独记录。
