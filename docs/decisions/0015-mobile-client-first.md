# ADR 0015：移动端优先，桌面端继续使用 Web

日期：2026-08-25

## 背景

Web/PWA 已覆盖桌面浏览器、离线壳和本地数据管理。产品更需要验证手机上的短课节学习、离线进度和复习体验。单独实现桌面客户端会增加安装、更新和平台测试成本，但短期不会带来新的核心能力。

## 决策

- 下一客户端优先 Android 与 iOS，独立桌面客户端不进入当前路线图。
- 移动端使用 Expo SDK 57 与 React Native；Android/iOS 共用工程。
- 移动端首版只提供 Learn 学习空间。无代码 Studio 继续使用 Web。
- Web 与移动端不共享界面组件，只共享协议、内置内容、Application Service、语言运行时和学习引擎。
- 移动端使用 Expo SQLite Repository；内置课程随应用包分发，核心学习离线可用。
- 备份继续排除密钥、凭据、临时请求和进行中的 Effect。
- AI、同步、商店分发和签名安装包分阶段加入，不阻塞首个可打包 MVP。

## 结果

客户端数量不会迫使学习引擎理解 React、React Native、IndexedDB 或 SQLite。移动端可以独立优化触控和小屏体验，同时保持与 Web 相同的课程、判定、掌握度与复习事实。桌面用户继续使用公开 Web/PWA。
