# ADR 0003：事件存储、掌握度投影和复习调度分离

## 状态

已接受。

## 决策

- 核心层只依赖 `SessionEventStore` 接口。
- 事件追加使用预期序号实现乐观并发控制。
- 提供内存存储用于测试和临时会话。
- 提供基于 Node.js 内置 SQLite 的本地持久化实现。
- 会话服务从事件存储恢复状态，再调用纯状态机推进课程。
- 掌握度作为事件流的投影结果，不直接写入会话状态机。
- 复习任务根据掌握等级和最后一次学习证据生成。

## 结果

课程推进、数据存储、掌握度判断和复习策略可以分别演进。未来替换为 PostgreSQL 或云端事件存储时，不需要修改状态机。
