# ADR 0014：通用 A1 主等级与日语 JLPT 辅助对齐

## 状态

已接受，2026-08-14。

## 背景

产品需要让同一套学习引擎、课程协议和客户端承载任意语种。日语课程又天然会被拿来与 JLPT 比较，但 JLPT 主要评估文字词汇、语法、阅读和听力，不直接评估口语产出、写作或互动；其官方 CEFR 参考也明确只覆盖考试实际测量的接收性技能。若把 JLPT 作为全产品主等级，会让其他语言失去共同标尺，也会弱化产品强调的场景任务和输出能力。

## 决策

- 所有语种的主课程等级使用 CEFR Can-do；当前内置课程目标为 A1。
- 各语言可以在同一 Course Pack 中增加语言专属辅助标签和覆盖矩阵，但不能替代通用主等级。
- 日语知识项可以标记 `jlpt-n5-relevant`，表示内容与 N5 范围相关；该标签不代表已经完整覆盖、通过审校或保证考试成绩。
- 只有在补齐并验证 N5 的文字词汇、语法、阅读、听力和模拟题覆盖后，才可使用“JLPT N5 备考完整”之类的声明。
- 当前暂停发音和音频功能，因此日语课程只能称为“A1 核心／N5 相关”，不能称为“N5 完整课程”或“N5 达标课程”。
- 诊断跳过属于语言无关的学习协议能力。课程只声明诊断练习及通过、学习两个目标步骤，播放器和未来移动端／桌面端按协议执行。

## 结果

课程作者可以按统一的 Can-do 方式设计多语言课程，同时为日语、粤语或其他语言保留考试体系、文字系统和语言特殊规则的适配空间。产品不会把“完成课程”“达到 A1”和“通过 JLPT N5”混为一谈，也不会因未来加入新客户端而复制诊断逻辑。
