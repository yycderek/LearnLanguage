# ADR 0011：统一界面与教学语言

## 状态

已接受。

## 决策

- 目标语言保持独立，由课程清单决定。
- 用户只设置一个设备本地的应用语言；它同时控制界面、课程解释、翻译、任务提示、日期格式和 AI 反馈。
- 第一批应用语言为中文（默认）和英文，使用 `app-locale` 偏好记录。
- 升级时优先读取新偏好；若不存在，则先采用旧界面语言，再采用旧教学语言，最后回退到中文。
- Course Pack 继续保存多个本地化版本。Studio 的统一语言选择器决定界面语言以及当前编辑的内容版本。

## 结果

学习者不会遇到界面与课程解释语言不一致的组合。客户端组件只接收一个 locale，因此移动端和桌面端也能复用同一偏好语义；旧偏好键只用于迁移，不再由界面分别修改。
