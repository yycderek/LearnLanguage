# LearnLanguage 架构草案

## 核心原则

不同语言共享学习流程，但语言差异不能简化为替换语料。系统将通用能力、语言规则和课程内容分成三个独立层次。

## 三层架构

### 通用学习引擎

负责能力目标、课前诊断、最小知识预教、支架输入、理解验证、渐进输出、AI 反馈、掌握状态、间隔复习和迁移测试。

### 语言包

当前负责书写系统、文本规范化、分词、语法知识类型、书写方向和难度框架。发音、录音、TTS/STT 与语音评分暂不进入当前实现范围；数据协议保留兼容字段，便于未来按需扩展。

### 课程包

负责 Can-do 目标、场景、知识点、语料、媒体资源、练习、角色任务、评分标准和复习任务。

## 用户内容

用户创建的内容默认保存为私人草稿，经过格式验证和课程预览后才能使用。未来可选择分享或发布，但不能直接修改官方课程数据。

## 首个通用化验证

1. 使用同一学习引擎加载两种语言包。
2. 两个语种的学习进度相互独立。
3. 用户可以创建、预览并运行一节私人课程。
4. 核心引擎不包含针对具体语言的条件分支。
5. AI 服务不可用时，确定性课程仍可运行。
