# A1 核心课程地图

## 通用能力域

内置课程 0.4.0 以 CEFR Can-do A1 为主等级，用相同的能力域组织不同语言，但不要求各语言使用完全相同的语法或文字教学：

| 能力域 | 日语 | 粤语 |
| --- | --- | --- |
| 文字／标音 | 平假名、片假名、常见假名变化 | 汉字＋粤拼、声母韵母、入声韵尾、六调 |
| 问候与身份 | こんにちは、〜は〜です、〜ですか | 你好、我叫〜、係／唔係 |
| 数字与时间 | 一至十、〜時、何時 | 一至十、〜點、幾點 |
| 地点、疑问与否定 | どこ、ここ／そこ／あそこ、ありません | 邊度、呢度／嗰度、冇／唔喺 |
| 购物与价格 | これ／それ／あれ、いくら、円 | 呢個／嗰個、幾多錢、蚊 |
| 交通与求助 | 駅、バス、〜に行きますか、すみません | 巴士、車站、去唔去、點去、幫幫手 |
| 服务场景迁移 | 饮料点单、冷热数量、堂食外带 | 饮料点单、冷热数量、堂食外带 |

每门课程包含 12 个 Can-do 课节和 36 个独立练习。前四个文字／标音基础课带基础诊断；答对后可沿短路径完成该课，答错则进入完整教学路径。诊断失败不生成掌握度证据。

## 日语与 JLPT N5

JLPT N5 适合作为日语课程的辅助覆盖标准，不适合作为通用产品主等级。当前状态为“N5 相关”，不是“N5 完整备考”：

| N5 能力 | 当前覆盖 | 结论 |
| --- | --- | --- |
| 平假名、片假名 | 已覆盖基础表和常见变化 | 核心覆盖 |
| 基础汉字与词汇 | 只覆盖场景所需小集合 | 需要扩充 |
| 基础语法 | 覆盖身份、疑问、否定、地点、时间、价格、移动和请求的起步形式 | 部分覆盖 |
| 短文／信息检索阅读 | 以单句和短表达为主 | 需要独立阅读模块 |
| 听力 | 当前产品阶段暂停音频 | 未覆盖 |
| 口语、写作、互动 | 由 Can-do 任务承载，但不属于 JLPT 直接测量范围 | 与 JLPT 分开报告 |
| N5 模拟题与计分 | 尚未建立 | 未覆盖 |

因此界面应显示“CEFR Can-do A1 核心”，日语内容可附“JLPT N5 相关”标签；在上述缺口补齐并经过母语者和考试内容审校前，不显示“N5 Ready”“N5 认证”或通过概率。
