## 选择入口

- [学习空间](https://learnlanguage-studio.yycderek.chatgpt.site/learn)：选择课程、学习、复习和管理本地数据。
- [课程创作空间](https://learnlanguage-studio.yycderek.chatgpt.site/studio)：创建、导入、编辑、预览和发布课程。

两个空间都不需要登录。界面语言与教学说明语言保持一致。

## 开始学习

1. 在学习空间选择内置课程或已导入课程。
2. 点击“一键开始学习”，直接进入首课；已有进度时优先继续未完成的课节。
3. 跟随课节提示完成练习；中途离开时点击“保存并退出”。
4. 回到学习首页查看“今天学什么”，继续课节或完成到期复习。

目标、每周节奏和基础检查都是可选的。在学习首页点击“设置计划”即可设置；基础检查只推荐起点，不限制手动选择课节。无需先设置计划才能开始学习。

课节中的例句提供“朗读”和另一档语速按钮；播放中再次点击可停止。声音由浏览器或手机系统提供，不使用 AI，也不会自动评价发音。在“设置 → 发音与系统语音”中可以为每个语种选择设备声音、默认语速并试听；偏好只保存在当前设备。没有检测到标签匹配的声音时，可使用系统自动选择或手动试听其他设备声音；若播放失败，请安装对应语言的系统语音包。

内置课程包括英语、日语、粤语和西班牙语核心入门内容。英语当前提供更完整的 A1 日常主题；日语包含 JLPT N5 相关内容，但不是完整的 N5 备考课程；西班牙语覆盖 A1 文字、基础结构和生活任务核心，但不是完整的 CEFR A1 认证课程。所有内置课程都不代表考试认证。

## 创建自己的课程

### 开始一份草稿

进入 Studio 后，按已有材料选择入口：

- 使用现成示例：在“从现有语言示例开始”选择语言。
- 创建新语种：点击“设置目标语言”，填写语言名称、文字系统和方向。
- 继续已有草稿：点击“选择草稿文件”；本机已保存的修订也可从“本地草稿”打开。
- 从素材生成：点击“导入素材”，选择目标语言，加入文本、网页、PDF 或 DOCX。文章、对话、歌词和字幕都可作为素材。编辑器内的入口叫“素材生成课程”。

进入编辑器后，也可展开“基本信息”中的“使用课程模板”。普通作者不需要编辑 JSON 或手动维护技术 ID。

素材生成的是私有草稿，包含候选知识点、难度估计和练习，发布前应逐项复核。歌词和字幕保留原分行；歌谱、音符和音频暂不解析。

### 编辑与查找内容

“基本信息”维护课程名称、简介、作者和许可证；“知识点”“例句”“练习”维护具体内容；“课节流程”按单元、课节、学习步骤组织和关联内容。

- 内容列表每页显示最多 25 项。“搜索当前内容”搜索当前分类的全部内容，不限于当前页。清空搜索可返回完整列表。顶部和底部均可翻页，也可选择页码直接跳转；翻页后定位到该页首项。新增内容会清空搜索，打开新增项所在页，并将光标放到新内容输入框。
- 引用选择器每页最多显示 20 项，可用“筛选引用”查找其他页的内容。翻页或筛选不会取消已有选择。
- 点击内容标题可折叠或展开。删除被引用的内容时会先确认，同时移除相关关联；其他内容仍保留。继续编辑前可点击“撤销删除”。

顶部“工具与设置”包含界面与讲解语言、使用帮助和 AI 设置。可用 Enter 展开、Esc 收起；点击外部或将焦点移出工具区也会收起。切换界面与讲解语言后，可以维护课程的中文或英文说明。

### 保存、预览与发布

1. 编辑时查看顶部自动保存状态；显示“修改已自动保存”后，工作副本已保存到当前浏览器。自动保存失败时先保留页面，按[常见问题](#常见问题)处理。
2. 点击“保存草稿”建立可恢复的修订。在“本地草稿”中按课程名称（包括旧名称）或语言代码搜索，点击“继续编辑”打开最新修订；展开“修订记录”可恢复或导出指定版本。自动保存工作副本与手动保存修订是两种不同操作。
3. 点击“预览学习流程”试做课程。预览使用临时档案，不写入真实学习进度；旁边折叠的“课程流程预览”用于查看步骤摘要。
4. 点击“查看发布检查”，用“去完善”定位问题。阻塞项必须完成，建议项不会阻止发布；未通过发布检查时仍可保存草稿。
5. 点击“校验并发布”，生成本机的固定课程版本。发布不会自动上传到网站或公共课程库。
6. 点击“安装到学习空间”，即可学习该版本。需要分享时，在学习空间的课程库找到课程并点击“导出备份”。自定义语种还需单独导出对应 Language Pack，供接收方先导入。

已发布课程的内容只读，仍可搜索和浏览。继续修改时点击“创建派生草稿”，编辑后重新检查、发布；原发布版本不会被直接改写。

## 添加其他语言

课程与语言能力分开管理。创建新语言课程时，可以使用现有 Language Pack，也可以在创作空间创建或导入自定义 Language Pack。

起始页、编辑器桌面侧栏和“语言包管理”支持“筛选目标语言”，可输入中文名、原名、英文名或语言代码。没有匹配结果时换关键词或点击“清除筛选”。手机编辑页从“语言包”进入管理页；桌面入口叫“语言包管理”。

Language Pack 描述文字系统、分词方式和可用练习能力。部分语言可以使用通用处理；特殊语言可以通过自己的适配器扩展，不要求所有语言完全采用同一规则。

## 安装、更新与离线使用

- 浏览器显示“安装到设备”时，可以把网站安装成独立窗口；不安装也能正常使用。
- “保护本地学习数据”会请求浏览器持久保存本站数据。浏览器可能拒绝，因此仍需定期备份。
- 新版本准备完成后会显示更新提示；只有点击“立即更新”才会刷新，避免打断当前学习。
- 首次在线打开学习或创作空间后，应用外壳会被缓存。断网时可以重新打开页面并使用已有本地数据。
- AI、网页素材导入和设备同步仍然需要网络。
- 例句朗读依赖设备系统语音；是否可离线、可用音色和具体口音由浏览器或操作系统决定。已选择的声音被系统移除后，应用会明确提示并回退到系统自动选择。

## 完整设备备份

路径：“课程库 → 课程与数据管理 → 完整设备备份”。展开管理区，点击“导出全部数据”保存文件；恢复时点击“选择完整备份”，先核对预览数量和冲突，再选择恢复方式。

完整设备备份包含：

- 已安装课程和用户课程；
- 课程草稿及修订；
- 自定义 Language Pack；
- 学习进度、复习安排和个人计划；
- 设备偏好。

恢复前会显示项目数量和同一 ID 的冲突：

- “合并恢复”保留备份中没有的本机项目，并用备份内容更新同 ID 项目。
- “清空本机后恢复”先清除当前持久数据，再恢复备份内容。

完整备份不包含 AI 密钥、同步令牌、当前作答会话或临时请求。备份可能包含私人课程文本，请妥善保存。

“学习档案备份”只迁移完成课节、掌握度、复习安排和个人计划，适合不携带课程与草稿的轻量迁移。

## AI 与隐私

Studio 中打开“工具与设置 → AI 设置”；学习空间中打开“设置 → 配置 AI”。选择服务商、填写兼容端点、模型与密钥，再点击“测试连接”。连接失败不影响基础学习和编辑。

- AI 是可选的；基础课程、确定性练习和课程编辑无需配置 AI。
- 自由回答反馈，或素材课程的翻译、语法、释义和细化难度估计，可以使用作者自己的 AI 服务。
- 配置个人 AI 后，课节底部的“AI 导师”可以解释当前步骤、给提示、换一个例子，或回答针对当前内容的问题。
- 导师只发送当前课节内容、当前回答和用户主动输入的问题；回复只作参考，不自动评分、不完成步骤，也不写入掌握度。
- 导师对话不持久化。API 密钥只保留在当前标签页，关闭标签页后清除，也不会写入完整设备备份。
- 启用素材 AI 增强时，相关素材会发送给用户选择的 AI 服务商。

## 更换设备

未配置同步时，浏览器数据不会自动迁移。更换设备前导出完整设备备份，在新设备打开“课程与数据管理”，选择备份文件，检查恢复预览后再确认恢复。

备份范围按客户端区分：

| 文件 | 用途与范围 |
| --- | --- |
| Web 完整设备备份 | 在 Web 端迁移课程、草稿、语言包、进度、计划和设备偏好 |
| Web 学习档案备份 | 迁移学习记录、复习和个人计划，不携带课程、草稿或 AI 设置 |
| 已发布 Course Pack | 分享课程内容，不携带个人学习进度 |
| Language Pack | 为接收设备补充自定义语种定义，不携带课程内容 |
| 移动端学习备份 | 恢复移动端学习记录、复习和个人计划；自定义课程和语言包需另行导入 |

不要把 Web 完整设备备份当作移动端通用恢复文件。Web 与原生移动端之间迁移课程时，按[移动端导入步骤](MOBILE_INSTALL.md#导入自定义课程与语种)使用已发布 Course Pack 和 Language Pack。

Web 端也可连接兼容的自托管同步服务；同步属于可选能力，不需要 LearnLanguage 账户。移动端首版不含云同步。

## 常见问题

### 换浏览器后，课程或草稿不见了

数据按网站地址和浏览器档案分别保存。先回到原浏览器、原网址和原档案检查；本地开发的不同端口也使用不同的站点数据。仍能打开原数据时，导出完整设备备份，再到新环境恢复。清除站点数据后，若没有备份，应用无法从账户或服务器找回。

### 修改没有保存，或找不到旧草稿

先保留当前编辑页面，查看自动保存状态，再尝试“保存草稿”。已保存的修订在“本地草稿”中。检查浏览器是否禁用了站点存储或空间不足；不要通过清空站点数据来修复保存失败。已有可用数据时，先导出完整设备备份。

### 为什么不能发布或不能编辑

草稿不能发布时，点击“查看发布检查”，逐项处理阻塞项；先保存草稿不会丢失未完成内容。若课程已经发布，内容只读，点击“创建派生草稿”后继续修改。

### 为什么只看到一部分知识点或引用

先检查搜索词，再查看页码。内容每页最多 25 项，引用每页最多 20 项；其他内容仍在下一页。筛选引用后看不到已选项，不代表选择已被取消。

### 例句朗读没有声音

检查设备音量，在“设置 → 发音与系统语音”试听可用声音。没有对应语音时安装系统语言语音包，或尝试系统自动选择。部分声音需要联网；原生 iOS 应用还需关闭静音模式。朗读无需 AI 密钥。

### AI 连接失败，或重新打开后需要密钥

检查所选服务商、端点、模型、密钥及网络，再运行“测试连接”，按界面返回的错误处理。密钥只在当前标签页会话中保留，关闭后重新填写是预期行为；不要把密钥写入课程或备份。

### 导入课程失败

确认文件类型：可编辑草稿从 Studio 的“选择草稿文件”导入，已发布课程从学习空间导入。自定义语种先导入 Language Pack，再导入 Course Pack。按界面提示检查版本、许可证或兼容性；不要手改已发布文件中的内容哈希来绕过校验。
