# LearnLanguage 使用手册

本手册解释学习、课程创作、安装、离线使用、数据备份和可选 AI。只想快速开始时，阅读对应章节即可。

## 选择入口

- [学习空间](https://learnlanguage-studio.yycderek.chatgpt.site/learn)：选择课程、学习、复习和管理本地数据。
- [课程创作空间](https://learnlanguage-studio.yycderek.chatgpt.site/studio)：创建、导入、编辑、预览和发布课程。

两个空间都不需要登录。界面语言与教学说明语言保持一致。

## 开始学习

1. 在学习空间选择内置课程或已导入课程。
2. 点击“一键开始学习”。首次学习时，可以设置目标与每周节奏。
3. 选择参加基础检查，或直接跳过；检查只推荐起点，不会限制手动选择。
4. 按“理解—练习—运用”完成课节。
5. 回到首页查看“今天学什么”。系统会根据未完成课节、实际进度和到期复习安排任务。

内置课程包括英语、日语和粤语核心入门内容。英语当前提供更完整的 A1 日常主题；日语包含 JLPT N5 相关内容，但不是完整的 N5 备考课程。所有内置课程都不代表考试认证。

## 创建自己的课程

1. 进入课程创作空间，选择目标语言。
2. 从模板开始，或粘贴文本、导入网页、上传 PDF 或 DOCX。文章、对话、歌词和字幕都可以作为素材。
3. 素材会按份生成私有课程草稿，并给出候选词汇、难度估计和确定性练习。
4. 用“单元 → 课节 → 学习步骤”组织内容，关联目标、知识点、例句和练习。
5. 修改会自动保存到当前设备；“保存草稿”会建立可恢复的明确修订。
6. 预览完整学习流程，处理发布检查中的必要问题，然后发布并安装到学习空间。
7. 需要分享时，导出已发布课程文件。

普通作者不需要编辑 JSON 或手动维护技术 ID。歌词和字幕会保留原分行；歌谱、音符和音频暂不解析。自动生成结果仍应在发布前复核。

## 添加其他语言

课程与语言能力分开管理。创建新语言课程时，可以使用现有 Language Pack，也可以在创作空间创建或导入自定义 Language Pack。

Language Pack 描述文字系统、分词方式和可用练习能力。部分语言可以使用通用处理；特殊语言可以通过自己的适配器扩展，不要求所有语言完全采用同一规则。

## 安装、更新与离线使用

- 浏览器显示“安装到设备”时，可以把网站安装成独立窗口；不安装也能正常使用。
- “保护本地学习数据”会请求浏览器持久保存本站数据。浏览器可能拒绝，因此仍需定期备份。
- 新版本准备完成后会显示更新提示；只有点击“立即更新”才会刷新，避免打断当前学习。
- 首次在线打开学习或创作空间后，应用外壳会被缓存。断网时可以重新打开页面并使用已有本地数据。
- AI、网页素材导入和设备同步仍然需要网络。

## 完整设备备份

路径：“课程库 → 课程与数据管理 → 完整设备备份”。

完整设备备份包含：

- 已安装课程和用户课程；
- 课程草稿及修订；
- 自定义 Language Pack；
- 学习进度、复习安排和个人计划；
- 设备偏好。

恢复前会显示项目数量和同一 ID 的冲突：

- “合并恢复”保留备份中没有的本机项目，并用备份内容更新同 ID 项目。
- “清空本机后恢复”先清除当前持久数据，再恢复备份内容。

完整备份不包含 AI 密钥、同步令牌、当前作答会话或临时请求。备份可能包含私人课程文本，请妥善保存。

“学习档案备份”只迁移完成课节、掌握度、复习安排和个人计划，适合不携带课程与草稿的轻量迁移。

## AI 与隐私

- AI 是可选的；基础课程、确定性练习和课程编辑无需配置 AI。
- 自由回答反馈，或素材课程的翻译、语法、释义和细化难度估计，可以使用作者自己的 AI 服务。
- API 密钥只保留在当前标签页，关闭标签页后清除，也不会写入完整设备备份。
- 启用素材 AI 增强时，相关素材会发送给用户选择的 AI 服务商。

## 更换设备

未配置同步时，浏览器数据不会自动迁移。更换设备前导出完整设备备份，在新设备打开“课程与数据管理”，选择备份文件，检查恢复预览后再确认恢复。

也可以连接兼容的自托管同步服务；同步属于可选能力，不需要 LearnLanguage 账户。
