# 移动端真机验收

本清单用于 Android 和 iOS 内部分发版本。每个平台至少使用一台实体设备完整执行一次，并记录设备型号、系统版本、安装包构建编号和结果。

## 安装与启动

- 从 EAS 内部分发页面直接安装签名包。
- 首次启动无崩溃、白屏或永久加载。
- 完全关闭应用后重新启动，学习记录仍然存在。
- 飞行模式下重新启动，内置课程仍可打开。

## 课程与练习

- 英语、日语、粤语和西班牙语课程列表可浏览。
- 打开一节课，完成选择、排序和文字输入练习。
- 正确与错误反馈可辨认，按钮和文本没有被安全区域、键盘或系统栏遮挡。
- 中英文界面切换后，界面语言与教学语言保持一致。

## 进度与复习

- 完成练习后，课程进度立即更新。
- 退出并重启应用，进度不丢失。
- 到期复习项能进入复习流程，完成后状态更新。

## 备份与恢复

- 导出备份成功，可从系统分享面板保存文件。
- 新增一条学习记录后导入旧备份，较旧数据不会静默覆盖较新数据。
- 清空本地数据后导入有效备份，课程进度和复习任务恢复。
- 无效文件或错误格式显示可理解的错误，不导致崩溃。

## 设备交互

- 小屏与大屏设备上主要操作可见。
- 打开软键盘后，当前输入框和提交按钮可访问。
- 深色与浅色系统主题下文字对比度可读。
- 屏幕旋转、切后台、系统内存回收后返回应用，不出现数据损坏。

## 通过条件

- 没有阻断安装、启动、学习、保存或恢复的缺陷。
- 没有数据丢失或备份覆盖错误。
- Android 和 iOS 各有一份完整验收记录。
- 非阻断视觉问题可记录后进入下一版本，不得隐藏已知限制。
