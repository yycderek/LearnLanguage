# LearnLanguage 实施路线

## 当前目标

在不保留旧本地数据兼容的前提下，把现有 Web 原型重构为可供 Web、移动端和桌面端共同使用的无头语言学习平台。

## R1：协议与测试基线

- 建立 `@learn-language/protocol`，成为课程和语言定义的唯一来源。
- 移除 Web 与根项目的重复类型。
- 统一练习类型 ID，移除语音相关协议。
- 建立拉丁文字、CJK、RTL、组合字符和缺少专用适配器的课程样例。
- 为 Schema、领域引用、导入导出和不支持能力编写详细测试。

## R2：无头引擎与应用层

状态：第一条垂直链路已于 2026-08-09 完成。

- [x] 引擎实现 Command -> Event/Effect/State。
- [x] Application 实现事务、Repository 和持久化 Effect 队列。
- [x] 将开始课节、提交练习、完成课节作为第一条完整垂直链路。
- [x] Web 的课节状态推进替换为公共引擎。

## R3：本地存储与两个产品空间

状态：已于 2026-08-09 完成。

- [x] Web 使用新的 IndexedDB 数据库，不迁移旧 LocalStorage 数据。
- [x] 独立 Learn 和 Studio 路由、导航及状态。
- [x] Studio 预览使用临时档案，绝不写入真实学习进度。
- [x] 区分安装发布课程与导入创作素材。

## R4：内容发布、语言能力与复习

- [x] 分离课程进度、掌握证据和版本化复习调度。
- [x] AI 仅作为可持久化的可选 Effect，输出经过校验并由用户审核。
