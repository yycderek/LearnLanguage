# LearnLanguage 实施路线

## 当前目标

在不保留旧本地数据兼容的前提下，把现有 Web 原型重构为可供 Web、移动端和桌面端共同使用的无头语言学习平台。

## R1：协议与测试基线

- 建立 `@learn-language/protocol`，成为课程和语言定义的唯一来源。
- 移除 Web 与根项目的重复类型。
- 统一练习类型 ID，移除语音相关协议。
- 建立拉丁文字、CJK、RTL、组合字符和缺少专用适配器的课程样例。
- 为 Schema、领域引用、导入导出和不支持能力编写详细测试。

## R2：无头引擎与应用层

状态：第一条垂直链路已于 2026-08-09 完成。

- [x] 引擎实现 Command -> Event/Effect/State。
- [x] Application 实现事务、Repository 和持久化 Effect 队列。
- [x] 将开始课节、提交练习、完成课节作为第一条完整垂直链路。
- [x] Web 的课节状态推进替换为公共引擎。

## R3：本地存储与两个产品空间

状态：已于 2026-08-09 完成。

- [x] Web 使用新的 IndexedDB 数据库，不迁移旧 LocalStorage 数据。
- [x] 独立 Learn 和 Studio 路由、导航及状态。
- [x] Studio 预览使用临时档案，绝不写入真实学习进度。
- [x] 区分安装发布课程与导入创作素材。

## R4：内容发布、语言能力与复习

状态：已于 2026-08-09 完成。

- [x] 完成草稿校验、不可变发布、内容哈希、来源和许可证。
- [x] 实现通用文本核心、可组合语言能力与显式降级机制。
- [x] 分离课程进度、掌握证据和版本化复习调度。
- [x] AI 仅作为可持久化的可选 Effect，输出经过校验并由用户审核。

## R5：可选服务与开源发布

状态：技术准备已于 2026-08-09 完成；仓库继续保持 private，等待维护者明确批准公开可见性。

- [x] 定义公开同步协议和服务端能力发现。
- [x] 提供可选参考后端，不影响纯本地完整使用。
- [x] 补齐 Apache-2.0、贡献、安全、治理和自部署文档。
- [x] 建立详细 CI、迁移固定样例和 GitHub 预发布通道。

## R6：多教学语言与语言运行时

状态：已于 2026-08-09 完成。

- [x] 明确区分目标语言和应用语言；应用语言偏好保存在设备端，默认中文。
- [x] Learn 首页、课节播放器、复习与 AI 反馈支持中文和英文教学语言，并采用确定性内容回退规则。
- [x] Studio 可分别维护课程的中文和英文本地化内容，自定义 Language Pack 可填写中、英和本地名称。
- [x] 建立客户端无关的 `@learn-language/language-runtime`，实际执行规范化、分词与书写系统检测；能力不再只靠声明。
- [x] 界面与教学内容使用同一个设备语言偏好；Learn 与 Studio 均支持中文和英文，并迁移旧的独立偏好。
- [x] 增加结构化练习渲染器和多课节可视化创作。
- [x] 建立首个完整中英双语课程库：日语、粤语各 3 个独立入门课节，附读音、练习与内容完整性测试。

## R7：设备本地课程库

状态：已于 2026-08-11 完成。

- [x] Learn 提供独立课程库，区分内置课程、用户课程、未安装与已安装状态。
- [x] 内置课程以带来源、许可证和内容哈希的不可变 Course Pack 安装。
- [x] 支持课程安装、卸载和兼容版本更新；卸载保留学习记录。
- [x] 更新前检查课程身份、语言、Schema、已学课节、当前步骤和掌握知识引用。
- [x] 兼容更新原子替换课程并将学习记录迁移到新课程版本。

## R8：课程包文件流转

状态：已于 2026-08-11 完成。

- [x] 课程库支持直接选择本地 Course Pack JSON 文件，无需复制或编辑 JSON。
- [x] 导入限制为 5 MB，并要求课程处于已发布状态且通过 Schema、领域引用和内容哈希校验。
- [x] 同 ID 文件作为版本更新处理，沿用 R7 的进度兼容检查和原子替换。
- [x] 已安装的发布课程可以导出为带稳定文件名的完整备份，支持重新导入往返。

## R9：学习档案备份与恢复

状态：已于 2026-08-11 完成。

- [x] 无账户用户可以把设备上的课程完成记录、掌握度、复习计划和复习结果导出为独立档案。
- [x] 档案明确排除课程内容、草稿、偏好、AI 设置、密钥、学习答案、进行中步骤和待处理 Effect。
- [x] 恢复文件限制为 5 MB，并对格式版本、日期、枚举、数量和重复课程 ID 做严格校验。
- [x] 恢复按课程 ID 与更新时间合并；旧备份不得覆盖更新的本地学习记录。
- [x] 多课程记录在 IndexedDB 的单次事务中恢复，未安装课程的记录可等待课程重新安装。

## R10：Studio 草稿管理

状态：已于 2026-08-11 完成。

- [x] Studio 提供独立草稿管理页，并与 Learn 课程库和学习档案界面保持视觉与数据边界。
- [x] 本地草稿按稳定草稿 ID 聚合，显示全部保留修订，并允许恢复任意修订继续编辑。
- [x] 支持导入、导出未发布的标准 Course Pack JSON；不引入第二种课程协议或要求用户编辑 JSON。
- [x] 导入文件限制为 5 MB，发布或归档课程不得伪装成可编辑草稿。
- [x] 删除草稿前要求确认，删除全部修订但保留当前编辑器内容，避免意外清空未保存修改。

## R11：Language Pack 管理与迁移

状态：已于 2026-08-11 完成。

- [x] Studio 提供独立 Language Pack 管理页，清楚区分内置定义和用户自定义定义。
- [x] Language Pack 可以作为标准 JSON 文件导入、导出，不与 Course Pack 或学习档案混装。
- [x] 文件导入限制为 1 MB，并检查唯一主要书写系统、重复 script code、适配器字段和受支持能力。
- [x] 内置 Language Pack 不可覆盖或删除；自定义定义被编辑器、草稿或已安装课程引用时禁止删除。
- [x] 替换仍被课程引用的自定义定义前明确警告分词与书写规则可能变化。

## 暂不实施

- 发音训练、录音、TTS、STT 和语音评分。
- 任意第三方 JavaScript 运行时插件。
- 实时多人协作编辑。
- 必须登录或必须联网的学习流程。
