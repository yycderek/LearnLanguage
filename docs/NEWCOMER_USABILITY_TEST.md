# 新手可用性测试

本测试用于验证普通学习者和不懂代码的课程作者能否理解并完成 LearnLanguage 的核心流程。它补充自动化回归，不把测试主持人的解释当作产品成功。

## 参与者

每轮建议 3–5 人，至少包括：

- 1 名从未使用过 LearnLanguage 的语言学习者；
- 1 名不懂编程、但制作过讲义或课程的人；
- 1 名既不熟悉语言学习软件，也不熟悉本项目的人。

参与者不得提前阅读 README 或使用手册。不要使用真实 API 密钥、私人课程或包含个人信息的备份。

## 测试环境

- 使用新建浏览器档案或清空后的本地开发版本；
- 桌面和手机窄屏至少各完成一轮；
- 界面语言由参与者自行选择；
- 录屏、录音或收集个人信息前必须取得同意；
- 主持人只读任务，不解释按钮位置和产品术语。

## 20 分钟任务

### 任务 1：开始学习

向参与者说明：“你想从零开始学习一门语言，请找到合适课程并开始第一课。”

记录：

- 从进入页面到开始第一道练习的时间；
- 是否误入 Studio；
- 是否理解课程目标、预计用时和入学评估；
- 第一次停顿超过 10 秒的位置。

通过标准：3 分钟内进入练习；不需要主持人指路；不会把日语和粤语理解成平台仅支持的语言。

### 任务 2：保存、退出和继续

向参与者说明：“现在先退出这节课，关闭页面，再回来继续。”

记录：

- 是否主动使用保存退出；
- 是否理解数据保存在当前设备；
- 重新打开后是否找到未完成课节和今日安排。

通过标准：无需账户完成恢复；参与者能说明进度仍在当前设备。

### 任务 3：创建自己的课程

向参与者说明：“你要为一门没有现成课程的语言设计入门课，不写代码。创建语言，保存草稿并预览学习流程。”

记录：

- 是否能区分 Learn 和 Studio；
- 是否找到自定义语言入口；
- 是否尝试编辑 JSON；
- 从进入 Studio 到完成预览的时间；
- 无法理解的课程术语。

通过标准：8 分钟内完成；不需要编辑 JSON；理解保存、预览、发布和安装是不同动作。

### 任务 4：数据与可选 AI

向参与者说明：“如果要换设备，你会怎样带走课程和进度？如果不想使用 AI，能否继续学习？”

记录参与者会点击什么，并请其用自己的话说明：

- 完整设备备份和学习档案备份的区别；
- AI 是否必须；
- API 密钥保存范围；
- 删除数据会影响什么。

通过标准：能找到完整设备备份；明确 AI 可不设置；删除前能看懂影响范围和备份建议。

严重度使用以下定义：

- P0：无法开始学习、数据丢失或误导用户提交秘密信息；
- P1：核心任务无法独立完成；
- P2：能够完成，但出现明显误解、绕路或超过目标时间；
- P3：文案、布局或反馈可优化，不阻止任务。

## 结果与决策

每轮结束后只汇总行为和问题，不保存答案正文、API 密钥或课程原文。

- 任一 P0：停止发布，先修复并重新测试；
- 同一 P1 被 2 人遇到：进入下一开发批次，修复后重测；
- 任务 1 成功率低于 80%：优先调整首次入口；
- 任务 3 成功率低于 70%：优先简化 Studio 术语和创建路径；
- 任务 4 理解率低于 80%：改写设置、备份和 AI 隐私说明。

测试结论必须注明参与人数、版本、设备和未覆盖范围。没有实际参与者时，只能标记为“测试方案已准备”，不能写成“新手测试通过”。
