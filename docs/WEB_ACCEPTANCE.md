# Web/PWA 产品验收

本清单用于公开 Web/PWA 版本。目标是验证普通学习者、课程作者和本地数据管理三条核心路径，不把单元测试通过等同于完整产品验收。

## 自动化验收基线

浏览器旅程位于 `apps/web/tests/e2e/product-journeys.e2e.ts`，每项同时在桌面 Chromium 和 Pixel 7 移动视口运行。

| 领域 | 自动化证据 |
| --- | --- |
| 首次使用 | 根路径进入 Learn、首次帮助、语言中立入口、无样式丢失和横向溢出 |
| 学习闭环 | 一键开始、可选基础检查、个人计划、进入课节、保存退出、刷新后恢复 |
| PWA 与离线 | Service Worker 接管后断网重载，Learn 壳和离线状态仍可用 |
| 无障碍与语言 | 跳到主要内容、键盘焦点、可见表单标签、中英文 `lang` 切换 |
| 备份恢复 | 完整备份校验、恢复前预览、实际合并恢复和重新载入 |
| 课程迁移 | 非官方课程信任确认、Course Pack 导入、兼容更新和导出文件名 |
| 个人 AI | 模拟官方接口完成连接测试；模型与服务商持久化，API 密钥仅存当前标签页 |
| Studio | 创建自定义语种、保存修订、预览课程、素材生成草稿和刷新恢复 |
| 数据控制 | 删除全部数据确认、单课程重置范围和课程内容保留 |

运行命令：

```bash
pnpm --dir apps/web test
pnpm --dir apps/web lint
pnpm --dir apps/web test:e2e
```

2026-08-30 本地生产构建验收结果：桌面和移动 Chromium 共 22 条旅程通过；Web lint 0 个错误。现有 5 个内部导航警告保留，其中数据库清空与重建必须完整重载页面。

## 每次公开发布前

- 使用新的浏览器档案打开 `/learn`，确认不需要 ChatGPT 或 LearnLanguage 账户。
- 分别完成中文、英文首次使用路径，确认界面和讲解语言一致。
- 安装一门内置课程，进入首课，保存退出并重新打开。
- 创建一个非内置语种草稿，保存、刷新、预览并导出。
- 导入已发布 Course Pack，确认非官方来源提示、版本和许可证清晰。
- 导出完整设备备份；在空浏览器档案中预览并恢复，确认课程、草稿和进度数量。
- 安装 PWA 或完成一次离线重载，确认本地学习仍可进入，联网能力明确不可用。
- 不配置 AI 时完成确定性学习；配置测试服务时确认密钥不会进入 IndexedDB 或备份。
- 在桌面和窄屏各检查一次主要页面，没有白屏、无样式文字页、遮挡或横向滚动。
- 检查 GitHub CI 为绿色，并把 commit、已知限制和用户可见变化写入发布说明。

## 产品观察

自动化只能验证行为稳定，不能证明文案和教学节奏容易理解。真实观察使用[新手可用性测试](./NEWCOMER_USABILITY_TEST.md)，记录首次开始首课所需时间、是否误入 Studio、是否理解本地数据与备份、是否知道 AI 为可选，以及中途放弃的位置。观察记录不采集答案正文、AI 密钥或其他隐私数据。测试脚本和判定标准已经准备；在实际参与者完成前，不宣称新手测试通过。

## 当前非阻塞限制

- 移动端签名包和真机验收已独立暂缓，不影响 Web/PWA 发布判断。
- 当前课程是入门课程，不宣称完整 CEFR 或 JLPT 考试认证。
- 发音、录音、语音识别和语音评分不在当前范围。
- 西班牙语内置课程继续延期；自定义西班牙语课程仍可通过 Language Pack 和 Course Pack 创建。
